## 19 October 2026 — Reading notation through code

Math as Code connects familiar programming ideas with mathematical notation. Start with a symbol, compare its equation with code, then try the topic's calculation and understanding check.

The guide covers arithmetic, vectors, matrices, sets, logic and introductory calculus. Examples are available in JavaScript, Python, C and Rust. The original English guide, Python edition and Chinese translation remain available from the sidebar.

Probability and statistics now connect the reference to a separate [ML and deep learning path](./ml-deep-learning.md#the-final-boss). It starts with a complete training objective, unpacks the pieces using the same tiny network, and ends with executable backpropagation and training.

Topics open directly in the reader. Search finds a topic, and Previous/Next follows the guide in order. There is no account to create; reading and practice progress stay in your browser.
